# Página de Actividades Académicas

Herramienta de trabajo de la comisión de Actividades Académicas (Derecho, UBA): tareas, proyectos y actividades por mesa, banco de ideas, reuniones con punteo y acta, actualización semanal e informe de coordinación.

- **Primer ingreso:** la primera cuenta que se registra queda como responsable. Las siguientes quedan pendientes hasta que la responsable las aprueba en *Integrantes*.
- **Tecnología:** Next.js + Supabase (base de datos, login y permisos) + Vercel.
- **Para seguir desarrollándola:** ver `CLAUDE.md`.

Repositorio privado. No contiene datos personales: viven en la base de Supabase, con acceso controlado.
